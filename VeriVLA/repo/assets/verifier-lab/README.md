# VeriVLA 交互实验室

打开 `../../verifier-lab.html` 即可离线使用；分享时保留整个 `repo` 文件夹的相对路径。

页面包括模块数据流、五步 latent 预演、注意力数值实验、源码张量尺寸和代码片段。图形与分数是教学示例；注意力实验实际计算 LayerNorm、Q/K/V 投影、掩码、softmax 和 V 加权和，但省略 RoPE、残差与 FFN，不运行预训练模型。

代码依据官方仓库提交 `f95ab142d6b5b247b47b36137352eb6289dd86a7`；示例尺寸不代表已公开的实验 checkpoint 配置。全部源码入口和事实边界已标在页面内。

公式和图表依赖已本地打包：KaTeX 0.16.9、Mermaid 10.9.3；许可证随 vendor 目录保存。
